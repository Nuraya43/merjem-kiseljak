# Cvjećara Merjem — Kiseljak

Responzivna web stranica na bosanskom jeziku. Otvorite `index.html` u pregledniku; instalacija i build nisu potrebni.

## GitHub Pages

U postavkama repozitorija otvorite Settings → Pages, odaberite Deploy from a branch, granu main i mapu / (root).

## Dopuna podataka

U `index.html` dopunite telefon, tačnu adresu i radno vrijeme. Obrazac priprema tekst upita za preuzimanje; ne šalje poruke niti narudžbe. Fotografije su ilustrativne i učitavaju se s Unsplasha; fontovi se učitavaju s Google Fonts.
